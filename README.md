# just-interval-trainer

相対音感とハモリの感覚を育てるための、ブラウザだけで動く練習ページです。

- **純正律：聴く特訓** (`listening.html`)：2音を同時に鳴らし、片方を動かして唸りが消える純正音程を探します。
- **純正律：歌う特訓** (`singing.html`)：主音のドローンに合わせて指定の音を歌い、ずれをセント単位で表示します。マイクを使います（ヘッドホン推奨）。

インストールは不要です。GitHub Pages で公開したページを Chrome / Edge / Safari で開いてください。
マイクは https で配信されたページでのみ使えるため、ローカルで試す場合は `python3 -m http.server` などで localhost から開いてください。
